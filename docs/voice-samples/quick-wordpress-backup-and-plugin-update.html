Updating plugins the Easy Way

It's been about one month since my previous backup and plugin / wordpress updates on this particular example site.  In one month, a wordpress site can certainly fall prey to an attack if a security whole has been discovered.   It is certainly wise to ensure no security updates have been released at all times.

However, if for some reason your site is a little behind in its updates, theres no better time than the present to get things updated.  

Here, I show you how easy it is to create a full site backup, perform all necessary updates and be done in about 5 minutes.
